- Use the CRISPE prompting method listed below. A more in-depth explanation is described in the following video.
  - Context — Give the model the background: situation, goals, constraints, and the audience so it understands why the task matters.
  - Role — Tell the model what persona, expertise level, or viewpoint to adopt (e.g., "act as a senior data analyst").
  - Instruction — State the concrete task and the desired action, including why it’s being done.
  - Specification — Define required format, length, tone, sections, and any mandatory elements or constraints.
  - Performance — Set quality criteria, success metrics, limits, and things to avoid so outputs meet your standards.
  - Example — Provide positive examples (and optionally negative examples) that show what “good” output looks like.
